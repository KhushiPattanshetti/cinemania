*Cinemania: Personalized Movie Recommendation System*
Cinemania is a movie recommendation system that suggests movies based on user preferences and mood. The project leverages a regression-based model to provide accurate recommendations using user ratings and movie metadata.

*Features*
Movie recommendations tailored to user preferences.
Intuitive and responsive frontend built with HTML, CSS, and JavaScript.
Backend powered by a Random Forest Regressor for accurate predictions.

*Technology Stack*
Frontend
HTML: Markup for the structure of the web pages.
CSS: Styling for a responsive and visually appealing interface.
JavaScript: Client-side logic and API calls to the backend.
Backend
Python (Django): To serve the machine learning model and handle user interactions.
Scikit-learn: For implementing the Random Forest Regressor.

*Machine Learning Model*
The recommendation system uses a Random Forest Regressor to predict a user's rating for movies based on:
User ID
Movie metadata (genres, average ratings, etc.)
The top-rated movies for a user are recommended.
